# 2026-09-22 默认日程时长设置

## 用户原始需求

目前插件不允许用户手动设置默认时长：标题只提取到起始时间、没有结束时间时，统一固定生成 1 小时的日程。希望增加一个配置项，允许用户设置默认日程时长（单位：分钟），生成 ics 文件时以用户设置为准。

## 实现小结

- `src/main.ts`
  - `DiaryIcsSettings` 新增 `defaultEventDuration: number`，默认值 `60`（兼容旧数据，`loadSettings` 会自动合并默认值）。
  - `extractTimeFromTitle()` 增加参数 `defaultDurationMinutes`：仅匹配到单个时间时，用 `开始时间 + 默认时长` 计算结束时间，并对 24 小时取模以支持跨天（如 23:30 + 90 分钟 → 次日 01:00）。
  - 设置页在"自动提取时间段"开关下方新增"默认日程时长"文本框，只接受正整数，非法输入不保存。
- `src/lang.ts`：新增 `defaultDurationSetting` / `defaultDurationDesc` 中英文文案。
- 已通过 `npm run build`（tsc 类型检查 + esbuild）验证。
